# 12.1 日怒奥法教学

> 适用范围：日怒奥法，不包含奥术脉冲的天赋方案；默认已装备12.1四件套。

## 一句话循环

用奥术飞弹叠加奥术齐射；齐射达到条件后打奥术弹幕；触发棱彩飞弹时打棱彩飞弹；没有其他可用技能时读奥术冲击。

## 技能优先级

从上到下判断，满足条件就施放：

1. **奥术弹幕**：奥术之魂期间。
2. **奥术飞弹**：有节能施法，且奥术齐射少于12层。
3. **棱彩飞弹**：棱彩飞弹可用，且累积能量达到8层时优先施放，吃满四件套40%增伤。
4. **奥术弹幕**，满足以下任一条件：
   - 奥术齐射达到25层；
   - 奥术齐射至少12层，并且有节能施法；
   - AOE场景中，奥术齐射至少12层、奥术宝珠可用且目标不少于3个时，也可以提前打奥术弹幕；随后立即用奥术宝珠快速恢复奥术充能。
5. **奥术宝珠**：奥术充能少于3层。
6. **奥术冲击**：没有更高优先级技能时填充。
7. **奥术弹幕**：法力不足时泄掉奥术充能。

已经触发棱彩飞弹但累积能量未满时，可以短暂等待奥术飞弹叠层；如果无法及时叠满，或继续打弹幕可能再次触发棱彩造成覆盖，则直接施放棱彩飞弹，不要为了等8层造成溢出。

## 起手

### 起手一

预读奥术涌动 → 药水 → 奥术飞弹 → 饰品 → 奥术弹幕 → 大法师之触

### 起手二

预读奥术冲击 → 奥术宝珠 → 药水 → 奥术涌动 → 饰品 → 奥术弹幕 → 大法师之触

## 关键注意事项

### 奥术涌动结束前

奥术涌动剩余最后2秒时不要打奥术弹幕。

- 单体优先级：棱彩飞弹 → 奥术飞弹 → 奥术冲击。
- AOE优先级：棱彩飞弹 → 奥术飞弹 → 奥术宝珠／奥术冲击。

棱彩飞弹只有在能够于奥术涌动结束前完成施法时才优先；如果剩余时间不足以读完，则使用奥术飞弹，并在进入奥术之魂时立即打断引导转为奥术弹幕。

### 奥术之魂

- 进入奥术之魂后，如果正在引导奥术飞弹，立即打断引导。
- 奥术之魂期间直接连续施放奥术弹幕。
- 不要为了触发敏锐直觉而穿插其他技能。

## 二连飞弹

仅在以下条件同时满足时使用：

- 奥术齐射为0层；
- 至少有2层节能施法；
- 第一发是普通奥术飞弹，而不是强能飞弹。

操作方法：

1. 施放第一个奥术飞弹。
2. 在倒数第二跳与最后一跳之间衔接第二个奥术飞弹，使第一发的最后一跳正常结算。
3. 第二发会消耗最后一层节能施法，因此不再满足“奥术齐射至少12层且仍有节能施法”的提前弹幕条件。
4. 继续引导第二发，将奥术齐射尽量叠到25层，然后施放奥术弹幕。

这项操作不要求已经触发棱彩飞弹。其目的在于连续利用两层节能施法快速叠高奥术齐射，从而打出高层奥术弹幕，并提高触发棱彩飞弹的概率。在满足上述三个条件时，二连飞弹优先于“奥术齐射至少12层且有节能施法”的弹幕分支。

如果第一发触发强能飞弹，应完整引导，不使用上述二连截断操作。
